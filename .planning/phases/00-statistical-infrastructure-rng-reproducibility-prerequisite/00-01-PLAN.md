<objective>
Fix the confirmed OpenMP RNG data race in `precalculate_augmentations()` (CONCERNS.md "Known Bugs"; PITFALLS.md Pitfall 13) so that `RANDOM_SEED=42` actually guarantees identical augmented training inputs across repeated runs — a correctness precondition for every A/B comparison in Phases 1-3. Per the project's decision (STATE.md: "RNG race fix-vs-document is a judgment call... during Phase 0 planning") and the explicit ROADMAP.md success criterion wording ("fixed... rather than merely documented, unless a fix is explicitly judged infeasible"), this plan implements the fix — it is not infeasible: the simplest correct fix is a one-line removal of the `#pragma omp parallel for` directive, since `precalculate_augmentations()` is not the pipeline's wall-clock bottleneck (feature extraction and MLP training dominate, per CONCERNS.md), so trading its parallelism for correctness is essentially free.

Because there is no test framework in this repo (`make test` is a non-functional stub — CLAUDE.md, CONCERNS.md) and a real end-to-end reproducibility check via `make full` would cost 60-90 minutes per run (CLAUDE.md "Build & Run Commands"), this plan also creates a lightweight, fast, automated verification scaffold (`mode_verify_rng`) per the Nyquist rule mandate ("If no test exists... create that scaffold") — it isolates exactly the racy component (the augmentation pre-computation loop) and dumps its output for byte-level diffing between two runs in roughly 1-3 minutes instead of 60-90.

Purpose: Every downstream gap (Phases 1-3) depends on "same seed, same folds" being a true, verifiable guarantee — not an aspirational comment.
Output: A single-threaded, deterministic `precalculate_augmentations()`; a new `verify-rng` CLI mode; documented empirical proof of determinism in `results/rng_reproducibility_check.txt`.
</objective>

static void precalculate_augmentations(const Dataset *ds, int nf, float *aug_features)
{
    log_info("Pre-calculando aumentacoes de audio (8x per patologico)...");
#pragma omp parallel for schedule(dynamic, 1)
    for (int i = 0; i < ds->count; i++) {
        if (ds->patients[i].class_label == CLASS_NORMAL) continue;
        WavFile wavs[3]; int wav_ok[3];
        for (int v = 0; v < 3; v++) wav_ok[v] = (wav_read(ds->patients[i].vowel_paths[v], &wavs[v]) == 0);
        for (int aug = 0; aug < N_AUG_PER_SAMPLE; aug++) {
            float *feat_row = &aug_features[(i * N_AUG_PER_SAMPLE + aug) * nf];
            for (int v = 0; v < 3; v++) {
                if (!wav_ok[v]) continue;
                int ns = wavs[v].num_samples; float *buf = (float *)safe_malloc(ns * sizeof(float));
                memcpy(buf, wavs[v].samples, ns * sizeof(float));
                switch (aug) {
                    case 0: wav_aug_noise(buf, ns, 25.0f); break;
                    case 1: wav_aug_gain(buf, ns, 3.0f); break;
                    case 2: wav_aug_gain(buf, ns, -3.0f); break;
                    case 3: wav_aug_stretch(buf, ns, 1.10f); break;
                    case 4: wav_aug_stretch(buf, ns, 0.90f); break;
                    case 5: wav_aug_pitch(buf, ns, 1.5f); break;
                    case 6: wav_aug_pitch(buf, ns, -1.5f); break;
                    case 7: wav_aug_noise(buf, ns, 30.0f); wav_aug_pitch(buf, ns, 0.7f); break;
                }
                extract_vowel_from_float(buf, ns, wavs[v].sample_rate, &feat_row[v * FEATURES_PER_VOWEL]);
                free(buf);
            }
            feat_row[NUM_VOWELS * FEATURES_PER_VOWEL] = (float)ds->patients[i].age;
            feat_row[NUM_VOWELS * FEATURES_PER_VOWEL + 1] = (ds->patients[i].sex == 'm' ? 1.0f : 0.0f);
        }
        for (int v = 0; v < 3; v++) if (wav_ok[v]) wav_free(&wavs[v]);
    }
}
