Implement `#include "feature_select_paraconsistent.h"`, `#include "config.h"`, `#include
"utils.h"`, `<math.h>`, `<string.h>` at the top, matching `normalize.c`'s import-ordering style
(lines 8-13). Define `#define MIN_VAR 1e-16f` (SST floor, squared relative to a std-style floor
since SST is a sum-of-squares) and `#define MIN_STD 1e-8f` (global-std floor, same name/value as
`normalize.c`'s file-local constant, but redefined locally here per this project's per-file
`#define` convention — do not attempt to import normalize.c's macro across translation units).

Implement `static float feature_eta_squared(const float *x, const int *y, int n, int nf, int
feat_idx, int n_classes)`: accumulate `global_mean` over all `n` rows for column `feat_idx`;
accumulate per-class `class_sum[c]`/`class_n[c]` via `safe_calloc`; compute `ssb = sum_c
class_n[c] * (class_mean_c - global_mean)^2`; compute `ssw = sum_i (x[i,feat_idx] -
class_mean_{y[i]})^2`; `sst = ssb + ssw`; if `sst < MIN_VAR` return `0.0f` (constant feature, no
separability evidence — do NOT divide); else return `ssb / sst` (already bounded `[0,1]` by
construction, no separate normalization pass needed, unlike SPEC.md's rejected Fisher-ratio
approach). Free the two `safe_calloc`'d buffers before returning.

Implement `static float feature_lambda(const float *x, const int *y, int n, int nf, int
feat_idx, int n_classes, float global_std)`: floor `global_std` at `MIN_STD`; accumulate
per-class `sum`/`sum_sq`/`n` via 3 `safe_calloc`'d buffers; for each class with `class_n[c] >=
2`, compute population `std_c = sqrt(max(0, sum_sq/n - mean^2))`, `ratio = min(std_c /
global_std, 1.0f)`, accumulate into `lambda_sum`/`active_classes`; return `lambda_sum /
active_classes` if `active_classes > 0` else `0.0f`. This is deliberately UNWEIGHTED across
classes (not sample-count-weighted like `ssb`/`ssw` above) — RESEARCH.md's degeneracy proof shows
a sample-weighted version collapses `lambda` to a fixed function of `mu` alone
(`lambda=sqrt(1-mu)`), destroying the two-independent-evidence-source premise this Gc/Gct split
exists for. Do not "simplify" this to a weighted average even though it looks more consistent
with `feature_eta_squared()`'s weighting — the asymmetry is intentional and load-bearing (flagged
`[ASSUMED]` in RESEARCH.md's Assumptions Log A1, since the domain-specific precedent papers are
paywalled; this is the documented, deliberate substitute).

Implement `int paraconsistent_select(...)` per the public signature in the header: allocate
`mu`/`lambda`/`gc`/`gct` arrays of size `nf` via `safe_malloc`. Loop `j` from `0` to `nf-1`:
compute `global_mean`/`global_var`/`global_std` for column `j` over all `n` rows (same
accumulation shape as `feature_lambda`'s caller-side prep), call `feature_eta_squared(...)` into
`mu[j]`, call `feature_lambda(..., global_std)` into `lambda[j]`, set `gc[j] = mu[j] -
lambda[j]`, `gct[j] = mu[j] + lambda[j] - 1.0f`. Then the relaxation loop: `float
cur_gc_thresh = gc_thresh;` `for (int iter = 0; iter <= PARA_MAX_RELAX_ITERS; iter++)`: reset
`n_selected = 0`, loop all `j`, select `j` into `selected[]` if `gc[j] >= cur_gc_thresh &&
fabsf(gct[j]) <= gct_max`; `if (n_selected > 0) break;`; else (only if `iter <
PARA_MAX_RELAX_ITERS`) `log_warn(...)` naming the current/next threshold and iteration count,
then `cur_gc_thresh -= PARA_GC_RELAX_STEP`. After the loop, `if (n_selected == 0)`: `log_warn(...)`
stating the cap was exhausted with zero features selected and all `nf` features are being used as
fallback (mirror `smote_oversample()`'s exact fallback-message tone at line 314), then `for (j)
selected[j] = j; n_selected = nf;`. Copy `mu`/`lambda`/`gc`/`gct` into the optional
`mu_out`/`lambda_out`/`gc_out`/`gct_out` via `memcpy` only if each pointer is non-NULL. Free the 4
internal arrays. Return `n_selected`.

Never call `exit()`/`abort()` anywhere in this file for degenerate input — every guard path
(MIN_VAR, MIN_STD, empty relaxation) must degrade to a safe, logged, non-crashing fallback,
matching this codebase's established defensive philosophy (NaN/Inf swept to 0 in
`feature_extract.c`, SMOTE-03's empty-pool fallback).
