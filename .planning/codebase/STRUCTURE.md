## Directory Purposes

**`src/`:**
- Purpose: single flat directory holding every compilation unit; the `Makefile` compiles via `wildcard $(SRC_DIR)/*.c` so any new `.c` file dropped here is picked up automatically
- Contains: DSP/feature-extraction modules, dataset/CSV/WAV I/O, MLP core + training loop, metrics, k-fold, normalization, augmentation, and the `main.c` orchestrator
- Key files: `main.c` (orchestrator/entry point), `mlp.c` (network), `mlp_train.c` (training loop), `feature_extract.c` (extraction orchestration), `feature_spectral.c` (largest module, 877 lines — F0/formants/MFCC/CPP/glottal source)

**`include/`:**
- Purpose: public API declarations, one header per `src/*.c` file, plus the project-wide `config.h`
- Contains: struct definitions (`Dataset`, `FeatureMatrix`, `MLP`, `Layer`, `KFoldSplits`, `NormParams`, `MetricsResult`, `TrainHistory`, `SpectralFeatures`, `TemporalFeatures`, `WaveletFeatures`) and function prototypes
- Key files: `config.h` (every tunable constant — paths, feature counts, network sizes, hyperparameters, class weights)

**`build/`:**
- Purpose: compiler output (`.o` per source file + final `vocal_detect` binary)
- Generated: Yes (`make`)
- Committed: No (`.gitignore`: `build/`, `*.o`)

**`models/`:**
- Purpose: intended location for trained network weights / normalization params (`mlp_save`/`norm_save` binary format)
- Generated: Yes, in principle — but the current `mode_train()` in `src/main.c` never calls `mlp_save`, so the `.bin` files present here are stale leftovers from an earlier iteration, not reproducible by `make full` today
- Committed: No (`.gitignore`: `models/`)

**`results/`:**
- Purpose: pipeline outputs — feature cache (`features.csv`), aggregated metrics (`metrics_global.csv`), and a running history of training-run logs (`train_log_v*.txt`, manually redirected by the user, not auto-generated by the program)
- Generated: Yes (`features.csv`/`metrics_global.csv` by the program; `train_log_v*.txt` by manual shell redirection when invoking `make full`)
- Committed: Partially — `results/features.csv` and `results/extract_log.txt` are gitignored (regenerable cache); other CSVs/logs are tracked for historical record

**`saudavel/`, `laringite/`, `disfonia_psicogênica/`, `disfonia_funcional/`, `edema_de_reinke/`:**
- Purpose: raw SVD (Saarbrücken Voice Database) audio corpus, one directory per class, each containing per-patient numeric-ID subdirectories with a `vowels/` subfolder holding `{id}-{a,i,u}_n.wav`
- Generated: No — must be supplied externally (see `CLAUDE.md` Prerequisites)
- Committed: No (`.gitignore` lists each by name explicitly)

**`.planning/`:**
- Purpose: GSD (Get Stuff Done) workflow artifacts — codebase maps, phase plans, etc.
- Generated: Yes, by GSD commands/agents
- Committed: Project-dependent; contains `codebase/STACK.md`, `codebase/INTEGRATIONS.md`, and (after this run) `codebase/ARCHITECTURE.md`, `codebase/STRUCTURE.md`

## Key File Locations

**Entry Points:**
- `src/main.c`: CLI dispatch (`main()`), and the entire training/extraction orchestration (`mode_extract`, `mode_train`, `mode_validate_external` stub)

**Configuration:**
- `include/config.h`: the single source of truth for paths, audio params, class definitions, vowel names, feature counts (`NUM_TEMPORAL_FEATURES`, `NUM_SPECTRAL_FEATURES`, `NUM_WAVELET_FEATURES`, `FEATURES_PER_VOWEL`, `TOTAL_FEATURES`), MLP architecture sizes, dropout rates, training hyperparameters (LR, batch size, epochs, patience, L2, Adam betas, gradient clip, label smoothing, noise stddev), K-fold count, random seed, and per-class weights
- `Makefile`: compiler flags (`-O2 -Wall -Wextra -Wno-format-truncation -std=c99 -Iinclude -fopenmp -lm`), build/run targets

**Core Logic:**
- `src/main.c`: hierarchical late-fusion pipeline (see `ARCHITECTURE.md`)
- `src/mlp.c` + `include/mlp.h`: network layer implementation (forward/backward/Adam), BatchNorm plumbing (currently disabled — `use_bn[]={0,0,0}`)
- `src/mlp_train.c` + `include/mlp_train.h`: mini-batch training loop, cosine LR annealing, Macro-F1 early stopping, SWA accumulation (currently unused — never applied to final weights)
- `src/feature_extract.c` + `src/feature_temporal.c` + `src/feature_spectral.c` + `src/feature_wavelet.c`: feature computation pipeline
- `src/dsp_utils.c`: shared DSP primitives (FFT, autocorrelation, pre-emphasis, wavelet denoise)

**Testing:**
- No automated test suite exists. `make test` is defined in the `Makefile` but invokes `./build/vocal_detect test`, and `main()` has no `"test"` mode branch — this target currently exits with code 1 and a usage message. There are no unit test files (`*_test.c`, `test_*.c`) anywhere in `src/`.

## Naming Conventions

**Files:**
- `snake_case.c` / `snake_case.h`, module name matches its primary concern (`feature_spectral.c` ↔ `feature_spectral.h`, `mlp_train.c` ↔ `mlp_train.h`)
- One `.h`/`.c` pair per module; no header-only modules, no multi-file modules

**Directories:**
- Class-name directories at repo root use the literal SVD pathology name in Portuguese, lowercase with underscores (`disfonia_psicogênica` keeps the accented `ê`) — these names are hard-coded as string literals in `include/config.h` (`DATA_DIR_*` macros), not derived from any config file

**Functions:**
- `snake_case`, prefixed by module/domain: `mlp_*` (network ops), `dsp_*` (signal processing), `rng_*` (random number generation), `log_*` (logging), `wav_*` (WAV I/O), `wav_aug_*` (augmentation), `kfold_*`, `norm_*`, `metrics_*`, `csv_*`, `dataset_*`, `features_*` (note plural — extraction/matrix functions), `temporal_extract`/`spectral_extract`/`wavelet_extract` (feature-domain extractors, no shared prefix)
- Static (file-local) helper functions have no special prefix but are always `static` (e.g., `bn_init`, `layer_forward`, `argmax`, `cosine_annealing_lr` in `mlp.c`/`mlp_train.c`; `enumerate_class`, `associate_csv_metadata` in `dataset.c`)
- Mode dispatch functions in `main.c` use `mode_*` prefix (`mode_extract`, `mode_train`, `mode_validate_external`)

**Types:**
- `PascalCase` for structs/typedefs: `Dataset`, `Patient`, `FeatureMatrix`, `MLP`, `Layer`, `BatchNorm`, `KFoldSplits`, `FoldSplit`, `NormParams`, `MetricsResult`, `ConfidenceInterval`, `TrainHistory`, `EpochResult`, `TemporalFeatures`, `SpectralFeatures`, `WaveletFeatures`, `CsvData`, `CsvRecord`, `WavFile`, `LRModel`
- Preprocessor constants: `UPPER_SNAKE_CASE` (`TOTAL_FEATURES`, `MLP_HIDDEN1_SIZE`, `CLASS_WEIGHT_REINKE`), always defined in `config.h`, never scattered across other files
- Enums: `UPPER_SNAKE_CASE` values with a `PascalCase`-ish or descriptive typedef name (`LogLevel` → `LOG_DEBUG`/`LOG_INFO`/`LOG_WARN`/`LOG_ERROR`)

## Where to Add New Code

**New feature type (e.g., a new acoustic feature family):**
- Implementation: new `src/feature_<name>.c` + `include/feature_<name>.h` following the `temporal_extract`/`spectral_extract`/`wavelet_extract` pattern (struct of named `float` fields + one `*_extract(signal, n, sample_rate, out)` function)
- Wire into: `src/feature_extract.c` (`extract_vowel_features()`) AND `src/main.c` (`extract_vowel_from_float()` — the augmentation-path duplicate, currently kept in sync by hand)
- Update: `include/config.h` (`NUM_*_FEATURES`, `FEATURES_PER_VOWEL`, `TOTAL_FEATURES`), and the header-name array in `features_export_csv()` (`src/feature_extract.c`) — mismatches here silently misalign CSV columns
- Tests: none exist; validate manually via `make clean && make extract` and inspect `results/features.csv` column count against the new `TOTAL_FEATURES`

**New model architecture variant (e.g., deeper MLP per SPEC.md Gap 3):**
- Implementation: extend `src/mlp.c`/`include/mlp.h` (e.g., a `mlp_init_multi()` generalizing `mlp_init_dynamic()` to N hidden layers, as sketched in `SPEC.md`)
- Wire into: `src/main.c` fold loop, replacing/parameterizing the current `mlp_init_dynamic(&net_master[v], nf_vowel, 2)` / `mlp_init_dynamic(&net_expert[v], nf_vowel, 4)` calls
- Config: add new size/hyperparameter constants to `include/config.h` rather than hard-coding in `main.c`

**New preprocessing/balancing technique (e.g., Borderline-SMOTE per SPEC.md Gap 2):**
- Implementation: modify or add alongside `smote_oversample()`/`find_knn()` in `src/main.c` (currently inline, not in a separate module — consider extracting to `src/smote.c`/`include/smote.h` if it grows, matching the one-file-per-concern convention used elsewhere)
- Wire into: the two `smote_oversample(...)` call sites inside the per-vowel fold loop (Master and Expert paths)

**New CLI mode:**
- Implementation: add a `mode_<name>()` static function in `src/main.c`, add a `strcmp(mode, "<name>")` branch in `main()`
- If the mode needs a new Makefile shortcut, add a target mirroring `extract`/`train`/`full` in `Makefile` (`$(TARGET)` dependency + `./$(TARGET) <name>`)

**New metric:**
- Implementation: add to `src/metrics.c`/`include/metrics.h` following the existing `metrics_*(inputs..., output_ptr)` signature convention
- Wire into: must be explicitly called from `mode_train()` in `src/main.c` — adding a function to `metrics.c` alone does NOT make it run (see ARCHITECTURE.md's dormant-module anti-pattern; `metrics_bootstrap_ci`/`metrics_roc_auc`/`metrics_mcnemar` already exist unused for exactly this reason)

**Utilities:**
- Shared helpers (allocation, RNG, logging, timing): `src/utils.c`/`include/utils.h` — add new `safe_*`/`rng_*`/`log_*` style functions here rather than duplicating in a module

## Special Directories

**`build/`:**
- Purpose: compiler-generated object files and final binary
- Generated: Yes
- Committed: No

**`models/`:**
- Purpose: trained-model persistence (currently disconnected from the active training path — see ARCHITECTURE.md)
- Generated: Nominally yes via `mlp_save`/`norm_save`, but not currently invoked
- Committed: No

**`results/`:**
- Purpose: feature cache + metrics + training logs
- Generated: Mixed — `features.csv`/`metrics_global.csv` by the program, `train_log_v*.txt` by manual redirection
- Committed: Mixed — `features.csv` gitignored, most `.txt`/`.csv` logs tracked for provenance

**Class-name audio directories (`saudavel/`, etc.):**
- Purpose: raw dataset, external to the repository
- Generated: No — user-supplied
- Committed: No
